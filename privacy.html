VISION Studio

Privacy Policy

Last updated: 30 August 2026

Application scope

VISION Studio is a desktop creator application. It processes data only for TikTok accounts whose owners explicitly complete TikTok's authorization flow. This public website is documentation and support; it does not collect TikTok credentials.

Data accessed

  • Basic TikTok profile information returned after the account owner authorizes the application.
  • TikTok access and refresh tokens needed to use the authorized API scopes.
  • Video files, captions, titles, hashtags and publication settings selected by the account owner.
  • Publication identifiers and status information used to show whether a post is processing, published or failed.

Purpose and sharing

This data is used only to prepare, schedule, publish and report the account owner's content. It is not sold, rented or used for advertising, profiling or cross-service tracking. TikTok receives only the information and media required to perform the publication requested by the account owner.

Storage and security

Tokens, prepared media and scheduling data are stored on infrastructure controlled by the developer. Secrets are not embedded in this public website or committed to its source repository.

Retention, deletion and revocation

Prepared files may be deleted locally at any time. The TikTok connection can be revoked from the TikTok account's security settings or disconnected in VISION Studio; locally stored tokens are then deleted. Publication history may also be removed from the local application.
