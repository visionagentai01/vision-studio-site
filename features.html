VISION Studio

Features

Everything VISION Studio does happens in one desktop application, with the creator in the loop at every step.

Preparation

Clip discovery

Point VISION Studio at an original video or a source you are authorized to use. It analyses the material and proposes several vertical clips with suggested start and end points.

Vertical framing

Clips are reframed to 9:16 for TikTok, with safe zones respected so captions and interface elements do not cover the subject.

Subtitles

Spoken content is transcribed and burnt in as readable subtitles. The creator can correct any line before the clip is rendered.

Titles, captions and hashtags

A draft title, caption and a small set of relevant hashtags are proposed for each clip. All of them are editable.

Review and approval

Preview before anything is sent

Every clip is shown as a rendered preview with its caption. The creator can edit, regenerate or discard it.

Privacy level and interactions

VISION Studio queries TikTok for the privacy levels available to the connected account and lets the creator choose one, together with the comment, duet and stitch settings.

Explicit confirmation

Nothing is uploaded until the creator presses Publish or Schedule for that specific clip. There is no silent or automatic posting.

Scheduling

Approved clips can be queued for a chosen date and time. Scheduled items can be edited or cancelled at any moment before they are sent.

Publishing and follow-up

Direct Post via Content Posting API

The rendered file is uploaded straight from the creator's computer to TikTok using FILE_UPLOAD. No intermediate public video host is required.

Status tracking

VISION Studio polls TikTok's publish status and shows scheduled, processing, published and failed items separately, with the reason for any failure.

Account dashboard

Follower, like and video counts from the Display API give the creator a quick overview of the connected account.

Disconnect at any time

The TikTok connection can be removed from inside VISION Studio or from TikTok's own security settings. Locally stored tokens are deleted when the account is disconnected.
